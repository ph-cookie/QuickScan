# QuickScan

**約2MBの軽量アプリ。画面やカメラのQRコード・バーコードを、ホットキーでオフライン読み取り。**

Webページや資料にあるQRコードを、スマートフォンに持ち替えず、そのMacで読み取れます。URLなら接続先を確認してブラウザへ。文章や商品コードならクリップボードへ。Dockやメニューバーを占有せず、必要なときにホットキーで呼び出します。

コードの読み取りとURLの注意判定は、Macの中で完結します。インターネット接続や外部サービスへの送信は不要です。URLを開いた後のブラウザの通信は別です。

macOS 13 Ventura以降に対応。Apple Silicon・Intel両対応のUniversalアプリです。

## まずは、こんな使い方

| 読み取りたいもの | 操作 | 結果 |
| --- | --- | --- |
| 画面のQRコード | **⌥⌘Q** → コードを囲む | URLは確認バブル、文字列はコピー |
| 紙や別の端末のコード | **⌥⌘⇧Q** → カメラにかざす | 画面モードと同じ処理 |
| 商品のJAN・UPCコード | 画面を囲む、またはカメラにかざす | 数字と形式名をコピー |

ホットキー（操作コマンド）は設定画面から変更可能です。

商品名の検索やWi-Fiへの自動接続は行いません。読み取った内容を確認して、次の操作へ進むための小さな道具です。

## 特徴

- **アプリ本体は約2MB**：検証時は約1.97MB。必要な機能に絞り、外部依存ライブラリを使わず実装しています。
- **待機中は画面を占有しない**：Dock・メニューバーのアイコンなし。設定を閉じるとバックグラウンドで待機します。
- **読み取り・注意判定はオフラインで完結**：外部サービスへの照会、テレメトリ、読み取り履歴の保存はありません。
- **URLを勝手に開かない**：接続先ホストを表示し、必ず確認操作を挟みます。注意が必要なURLは通常のReturnでは開きません。
- **カメラは使うときだけ**：検出・Esc・30秒無操作で停止します。接続カメラはTabで切り替えられます。
- **扱う形式を選べる**：標準はQR・JAN/EAN・UPC。「すべて」でCode 128、DataMatrix、PDF417なども有効にできます。

## インストール

現在、Developer ID署名・公証済みの配布版は提供していません。ソースからビルドする場合は、**Xcode 15以降（Swift 5.9以降）** を用意してください。

```bash
git clone https://github.com/ph-cookie/QuickScan.git
cd QuickScan
./scripts/build.sh
open build/QuickScan.app
```

生成された `build/QuickScan.app` を `/Applications` または `~/Applications` へ移し、同じ場所から使うと権限の設定先を固定できます。移動後は、ビルド先のコピーを終了してから起動してください。スクリプトの初期設定は個人利用向けのアドホック署名です。Developer IDによる署名・公証とは異なります。

配布版を公開する場合は [GitHub Releases](https://github.com/ph-cookie/QuickScan/releases) に掲載します。公証済み・未公証の違いは各リリースの説明で確認してください。

## 初回設定と日常の操作

初回起動時に設定画面が開きます。ホットキーと読み取る形式を選び、設定画面を閉じると待機します。ログイン時起動とコピー時のシステム通知は、どちらも初期状態OFFです。

**権限は用途に応じて許可します。** 画面モードには画面収録、カメラモードにはカメラの許可が必要です。設定画面からmacOSの「プライバシーとセキュリティ」を開けます。許可の変更後は再起動が必要な場合があります。アクセシビリティ・入力監視の許可は不要です。

設定を開き直すには、Finderから同じQuickScanをもう一度開きます。終了は設定画面の「QuickScanを終了」です。

| 場面 | キー |
| --- | --- |
| 通常のURLを開く | Return |
| 警告のあるURLを開く | **⌥Return**。Returnだけでは開きません |
| URLをコピーして閉じる | ⌘C |
| キャンセル／閉じる | Esc |
| 複数コードから選ぶ | ↑↓、Returnで確定 |
| カメラを切り替える | カメラパネルでTab |
| 画面で見つからず、カメラへ切り替える | 「見つかりません」のバブルでC |

バブル表示直後の400msは誤操作を防ぐためキーを受け付けません。通常のバブルは15秒無操作で閉じ、警告URLは明示的な操作まで残ります。URL以外はすぐコピーし、数字だけの結果には `EAN-13: 4901234567894` のように形式名も付けます。コマンド風・複数行の内容は、貼り付ける前の確認を促す警告を表示します。

## 安全性とプライバシー

URLの注意表示は、サイトの安全性を保証するものではありません。ユーザー情報付きURL、IDN/Punycode、生のIPアドレス、http、非標準ポート、既知の短縮URLなどをローカルで検査します。表示にはパース後の接続先ホストを使い、不可視文字はエスケープして見えるようにします。

**見た目が正常なフィッシングサイトは判定できません。** URLの評判確認や短縮URLの展開、リダイレクト先の調査はしません。読み取った `javascript:`、`file:`、`data:` などは開かず、文字列としてコピーします。

画面の画像は一時PNGに保存し、解析後に削除します。ただし、クラッシュ・強制終了では次回起動まで残る可能性があります。次回起動時に専用一時ディレクトリを掃除します。メモリやディスクの物理的な消去は保証しません。

コピーした文字列はシステムのクリップボードに残ります。QuickScan自身はネットワーク要求を発行しませんが、URLを開いたブラウザやContinuity CameraなどのOS機能は通信する場合があります。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| 起動してもアイコンが見当たらない | バックグラウンドアプリの仕様です。Finderから再度開くと設定が表示されます |
| ホットキーが反応しない | 設定を開き、登録エラーを確認してください。他のアプリとの競合があれば変更します。読み取り処理中の追加入力は無視します |
| 範囲選択後に読めない／権限案内が出る | 画面収録の許可と、実際に起動しているアプリの場所を確認し、QuickScanを再起動してください |
| 「見つかりません」と表示される | コード全体を囲んでください。1次元バーコードは左右の白い余白も含めます。必要なら「すべて」の形式へ変更するか、Cでカメラへ切り替えます |
| カメラが映らない | カメラの許可、接続、他のアプリの使用状態を確認してください。接続が複数あればTabで切り替えます |
| ReturnでURLが開かない | 表示から400ms待ってください。警告URLは⌥Returnが必要です。理由と接続先を確認してから操作します |
| 設定やアイコンが古い | 別の場所にある旧版も含めてQuickScanを終了し、使うアプリを1つにして起動し直してください |
| macOSに起動を止められる | 入手元と署名・公証の有無を確認してください。個人ビルドの手順は上の「インストール」を参照してください。OSの保護機能を一括で無効化する必要はありません |
| ログイン時に起動しない | 設定のトグルとmacOSのログイン項目を確認してください。アプリを移動した場合は登録し直します |

解決しない場合は [Issues](https://github.com/ph-cookie/QuickScan/issues) へ、macOSのバージョン・入手方法・再現手順・権限状態を添えて報告してください。読み取った機密情報や、認証情報を含むURL・画像は投稿しないでください。

## ビルドとテスト

Swift・AppKitで実装し、外部依存ライブラリは使っていません。ソースのビルドは上の「インストール」の手順で行えます。テストは次のコマンドです。

```bash
./scripts/test.sh
```

開発時のXcodeテストは22件、失敗0件でした。実カメラ・画面収録・複数ディスプレイ・通信監視などには未検証項目があります。ビルド成功と実機での全動作確認は区別しています。
